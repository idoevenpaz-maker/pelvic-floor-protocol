# Pelvic Floor Protocol

A 12-week, 10-minute-a-day male pelvic floor program: strength and release work for erection firmness, mobility for flexibility, and a separate arousal-training module for ejaculatory control.

- Guided session timer for each phase (Foundation, Strength, Control) and a weekly release day
- 84-day progress log and weekly check-ins, stored on the device (with backup and restore)
- Installable as an app on phone or desktop, works offline

Static site: `index.html`, `manifest.webmanifest`, `sw.js` and icons. No build step.

Educational only; not a substitute for a medical assessment.
